About

My experience is mostly using JavaScript and its most widely used libraries, such as React, Next.js, and Node.js, to build a variety of applications, responsive web interfaces and robust back-end solutions. In addition, I have experience working with Linux, BASH, SQL and NoSQL databases, having also developed cross-platform solutions for web, mobile, and desktop environments using REST APIs, React Native, Expo, and Electron.

More recently, I have been expanding my knowledge of machine learning and applied AI. I have worked with Python libraries and frameworks such as NumPy, Pandas, scikit-learn, TensorFlow/Keras, PyTorch, Hugging Face Transformers, and LangChain, while studying concepts including supervised and unsupervised learning, neural networks, backpropagation, optimization, model evaluation, tokenization, embeddings, retrieval-augmented generation (RAG), LLM agents, and model integration. My focus has been on understanding how machine learning models and AI systems are trained, evaluated, and incorporated into practical software applications.
